# Rapport for skyssrefusjon

1. Sørg for at deltakere som skal ha skyssrefusjon har følgende i *SAD*

    - Haket av i *Rett reisepenger*
    - Skyss typekode som stemmer
    - Kommentar i *Skyss merknad*

2. [Filtrer frem senter](../felles/guie.pdf.md#filtrere-i-sits) i skjermbildet *SCL*[![bilde](../assets/images/gallery.svg){width="15"}](../../assets/images/meny_skjermbilde.webp){.glightbox}

3. Generer [*FOVO SKYSRE*](../felles/guide_pdf.md){.glightbox}

4. [Filtrer](../felles/guie.pdf.md#filtrere-i-sits) frem alle AP-deltakere ved ditt senter i skjermbildet *SPR*[![bilde](../assets/images/gallery.svg){width="15"}](../../assets/images/meny_skjermbilde.webp){.glightbox}

3. Generer [*FOVO SKYSRE2*](../felles/guide_pdf.md){.glightbox}

    Merk at dette må gjøres fra *All*

4. Behandle data videre utenfor SITS
