# Se timeplan for deltakere, rom og ansatte

## Timeplan for en lærer

1. [Filtrer frem lærer](../felles/guie.pdf.md#filtrere-i-sits) i skjermbildet *PRS* [![bilde](../assets/images/gallery.svg){width="15"}](../../assets/images/meny_skjermbilde.webp){.glightbox}

2. Fra toppmenyen går du til *Other* ⇒ *Timetable view* [![bilde](../assets/images/gallery.svg){width="15"}](../../assets/images/meny_top.webp){.glightbox}

3. Skriv inn ønsket periode

4. Trykk *Vis timeplan*

## Timeplan for deltaker

1. [Filtrer frem deltaker](../felles/guie.pdf.md#filtrere-i-sits) i skjermbildet *SPR* [![bilde](../assets/images/gallery.svg){width="15"}](../../assets/images/meny_skjermbilde.webp){.glightbox}

2. Fra toppmenyen går du til *Other* ⇒ *Event* ⇒ *Timetable view* [![bilde](../assets/images/gallery.svg){width="15"}](../../assets/images/meny_top.webp){.glightbox}

3. Skriv inn ønsket periode

4. Trykk *Vis timeplan*
