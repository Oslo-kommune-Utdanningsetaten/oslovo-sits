# Flytte timer mellom to SPR

1. Fra eVision gå til *SITS Bruker* ⇒ *Deltakerbehandling* ⇒ *Flytte timer og fravær mellom to SPR*

2. Fyll ut felt med ønskede verdier og trykk *Neste*

3. Se gjennom endringene som kommer til å gjøres og trykk *Bekreft* hvis alt er i orden

4. Se gjennom bekreftelse på hva som er gjort og enten *Avslutt* eller *Se kursoversikt*

    ??? warning "Jeg så nå at noe ble feil"

        Er du 100% sikker på hva som ble gjort og hvordan det skal være kan du flytte timer med å gjøre prosessen igjen.
        Er du usikker må du opprette en forespørsel i USD. Beskriv ønsket utfall.
