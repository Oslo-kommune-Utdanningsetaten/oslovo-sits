### Hvordan skal input fylles inn?

??? note "Navn på input-felt"
    | Kode | Beskrivelse |
    |------|-------------|
    | NOSF | Deltaker trenger opplæring i samfunnskunnskap |
    | NO | Deltaker trenger bare opplæring i norsk |
    | SF | Deltaker trenger bare opplæring i samfunnskunnskap |


??? note "Navn på et annet input-felt"
    | Kode | Beskrivelse |
    |------|-------------|
    | *TOM* | Deltaker trenger opplæring i samfunnskunnskap |
    | FF | Deltaker har fullført opplæring i samfunnskunnskap |
    | K | Deltaker trenger ikke samfunnskunnskap grunnet 6A |
    | FT | Deltaker har fått fritak fra samfunnskunnskap |
    | SFT | Deltaker skal søke fritak fra samfunnskunnskap |
    | V | Deltaker ønsker å ta samfunnskunnskap på et senere tidspunkt |
