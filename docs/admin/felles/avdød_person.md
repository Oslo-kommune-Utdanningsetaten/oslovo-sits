# Hvordan håndtere avdøde deltakere?

??? quote "Hvorfor må vi gjøre noe med disse?"
    Avdøde deltakere er mer enn sluttført.
    Vi ønsker ikke å sende ut flere brev til disse, og heller ikke stå i fare for å registrere noe nytt på dem.

## Hvordan håndtere en avdød deltaker?

1. Sluttfør deltaker som vanlig etter rutine LENKE_TIL_RUTINE_FOR_SLUTTFØRING
2. Informer superbruker på ditt senter om situasjonen til deltakeren
    1. Inkluder eventuell dokumentasjon på deltakers situasjon
