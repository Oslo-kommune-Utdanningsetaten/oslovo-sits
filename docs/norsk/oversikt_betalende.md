# Få oversikt over betalende deltakere

Rapporten NOVO REVRAP1 gir en oversikt over kursaktivitet for betalende deltakere i en gitt periode.

Rapporten kan kjøres for deltakere utenfor NNIR-ordningen og for deltakere med PLIKT under NNIR-ordningen.

## Filtrere frem betalende deltakere

=== "Deltakere utenfor NNIR-ordningen"

    1. Gå til skjermbildet *SPR* [![bilde](../assets/images/gallery.svg){width="15"}](../assets/images/meny_skjermbilde.webp){.glightbox}

    2. Fyll inn følgende felt [![bilde](../assets/images/gallery.svg){width="15"}](../assets/images/tmp.webp){.glightbox}

        |     |     |
        | --- | --- |
        | Program | NBET |
        | VO-senter | Ditt senter |

    3. Trykk F5 og velg *OK*

=== "Deltakere med PLIKT under NNIR-ordningen"

    1. Gå til skjermbildet *SPR* [![bilde](../assets/images/gallery.svg){width="15"}](../assets/images/meny_skjermbilde.webp){.glightbox}

    2. Fyll inn følgende felt [![bilde](../assets/images/gallery.svg){width="15"}](../assets/images/tmp.webp){.glightbox}

        |     |     |
        | --- | --- |
        | Program | NNIR |
        | VO-senter | Ditt senter |

    3. Klikk på *UDF*-knappen [![bilde](../assets/images/gallery.svg){width="15"}](../assets/images/meny_udf.webp){.glightbox}

    4. Skriv inn PLIKT i feltet *Rettigheter*

    5. Klikk på *Apply*

    6. Trykk F5 og velg *Yes*

## Ta ut rapport for betalende deltakere

1. Generer [*NOVO REVRAP1*](../felles/guide_pdf.md){.glightbox} fra *All* ⇒ *Gen + Print letters* og velg *Run*

    ??? quote "Brukerinput for **NOVO REVRAP1**"

        <div class="srl-table" markdown="1">

        |  |  |  |
        | --- | --- | --- |
        | Startdato | <span>*ddmmyyyy*</span> | Startdato for perioden du ønsker oversikt over |
        | Sluttdato | <span>*ddmmyyyy*</span> | Sluttdato for perioden du ønsker oversikt over |

        </div>

2. Klikk på *OK*

    ??? tip "Det tar lang tid å generere rapporten"

        Du kan følge med på fremdriften nederst til venstre i SITS.

3. Se gjennom rapporten [![bilde](../assets/images/gallery.svg){width="15"}](../assets/images/tmp.webp){.glightbox}

    Rapporten viser følgende:

    - SPR-kode
    - Navn
    - Kurstittel
    - Reg.nr
    - Del.timer
    - Startdato
    - Sluttdato

4. Lukk rapporten og velg *Yes* når du får spørsmål om du vil se *advanced message buffer* [![bilde](../assets/images/gallery.svg){width="15"}](../assets/images/tmp.webp){.glightbox}

5. Se gjennom meldinger for deltakere som ikke kom med i rapporten
